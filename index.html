Telegram Notify for OpenWrt

Repository for tg-notify and luci-app-tg-notify packages.
Send Telegram alerts when a new device connects to your network.

Installation

1. Determine your architecture (usually aarch64_cortex-a53 for modern routers like MT6000, Filogic, or mipsel_24kc for MT7621).

2. Add the repository to your OpenWrt (SSH):

OpenWrt 24.10 / Snapshot (aarch64_cortex-a53)
For modern devices: GL.iNet GL-MT6000 (stock 4.7+), Filogic 830, MT798x
echo "src/gz tg_notify https://andreqgav.github.io/openwrt-tg-notify/24.10/aarch64_cortex-a53" >> /etc/opkg/customfeeds.conf
opkg update
opkg install luci-app-tg-notify
Browse Files
